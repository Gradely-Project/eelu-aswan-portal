# منصة إدارة التراكات والأنشطة الطلابية | Branch Portal

منصة متكاملة لإدارة الأنشطة والتدريب العملي في البرانش، تتضمن إدارة التراكات، تسجيل حضور وغياب السيشنز، رفع ومشاركة الماتريال، إنشاء وتصحيح التاسكات مع مراقبة الديدلاين، احتساب درجات الترتيب التلقائي (Leaderboard)، وطباعة تقارير الطلاب.

---

## 🌟 المميزات الرئيسية للمنصة

1. **إدارة صلاحيات دقيقة ومحكمة (Role-Based Permissions):**
   - **الآدمن الرئيسي (Owner/Admin):** إدارة التراكات، اعتماد ومراجعة طلبات تسجيل الطلاب (Pending Approvals)، تشكيل فريق كل تراك (Head, Vice Head, 2 Core Team)، والتحكم في إعدادات نقاط الترتيب.
   - **الـ Chair Person ونائب الرئيس (Vice Chair / Assistant):** مراقبة شاملة لكل التراكات، الإحصائيات، كشوفات الحضور، والليدربورد بدون صلاحيات حذف أو تعديل الفرق (View-Only Monitoring).
   - **فريق التراك (Head, Vice Head, 2 Core Team):** صلاحيات محصورة داخل تراكهم فقط، يرون طلاب تراكهم فقط، ويديرون السيشنز، الغياب، التاسكات، وتصحيحها، مع إمكانية طباعة تقرير مخصص لطلاب تراكهم.
   - **الطلاب (Students):** إمكانية الاشتراك في أكثر من تراك، تصفح السيشنز والماتريال، تسليم حلول التاسكات بروابط Google Drive قبل الديدلاين، ومتابعة درجاتهم وترتيبهم في الليدربورد.

2. **نظام اعتماد تسجيل الطلاب (Student Approval Workflow):**
   - يسجل الطالب حسابه ويختار التراكات التي يرغب بها.
   - يدخل الحساب تلقائياً في حالة `قيد المراجعة (Pending)`.
   - لا يمكن للطالب تسجيل الدخول حتى يقوم الآدمن الرئيسي بالموافقة على حسابه من لوحة التحكم.

3. **إدارة السيشنز والماتريال (Sessions & Materials):**
   - إضافة جلسات وورش عمل مع التاريخ والوقت والمكان أو رابط الاجتماع.
   - إرفاق روابط الماتريال (Google Drive, Slides, GitHub Repos, Videos) مع أزرار مباشرة للطلاب.

4. **كشف الحضور والغياب الذكي (Attendance System):**
   - كشف غياب لكل سيشن مع خيارات (حاضر، غائب، معذور) وخانة ملاحظات.
   - زر سريع لتحديد الكل حاضر وحفظ الكشف.
   - احتساب نقاط الحضور تلقائياً وإضافتها في رصيد الطالب.

5. **نظام التاسكات والديدلاين (Tasks & Deadlines):**
   - إضافة تكليفات وتاسكات مع ديدلاين زمني دقيق.
   - يقفل التسليم تلقائياً عند انتهاء الديدلاين، مع إمكانية قيام قائد التراك بإعادة فتحه أو تمديد الوقت.
   - تسليم الحلول بروابط Google Drive أو GitHub مع ملاحظات الطالب.
   - شاشة تصحيح مريحة للمدرب لرصد الدرجة وكتابة فيدباك للطالب.

6. **لوحة الشرف والترتيب (Leaderboard):**
   - ترتيب فوري لكل تراك على حدة.
   - منصة تتويج (Podium) للمراكز الثلاثة الأولى (🥇 الذهبية، 🥈 الفضية، 🥉 البرونزية).
   - إمكانية إضافة بونص ونقاط مسابقات مع ذكر السبب.
   - معادلة حساب قابلة للتخصيص من قبل الآدمن أو الـ Chair.

7. **طباعة تقارير الطلاب (Printable Reports):**
   - صفحة تقرير كاملة ومجهزة للطباعة المباشرة والتصدير كـ PDF بمقاس A4.
   - تتضمن لوجو البرانش، بيانات التراك والتيم، مصفوفة درجات وغياب كل طالب، ومكان مخصص للتوقيعات والأختام.

## 🚀 تشغيل المشروع محلياً (Local Development)

```bash
# 1. تثبيت الحزم (إن لم تكن مثبتة)
npm install

# 2. تشغيل السيرفر المحلي
npm run dev
```

افتح المتصفح على: `http://localhost:3000`

## 🌐 الرفع على Vercel وربط Supabase (Production Deployment)

1. **إنشاء قاعدة بيانات على Supabase:**
   - افتح [Supabase](https://supabase.com) وأنشئ مشروع جديد.
   - انسخ رابط الاتصال من الإعدادات: `Settings -> Database -> Connection String (URI / Transaction Pooler)`.

2. **تجهيز ملف `prisma/schema.prisma` لـ Supabase:**
   - غيّر الـ `datasource` ليكون:
     ```prisma
     datasource db {
       provider = "postgresql"
       url      = env("DATABASE_URL")
     }
     ```

3. **الرفع على Vercel:**
   - ارفع كود المشروع على مستودع GitHub.
   - في Vercel، اختر **Import Project** من GitHub.
   - في إعدادات البيئة **Environment Variables** أضف:
     - `DATABASE_URL`: رابط الاتصال الخاص بقاعدة بيانات Supabase.
     - `JWT_SECRET`: أي مفتاح سري عشوائي طويل للأمان.
   - في خيار Build Command يتم تشغيل:
     ```bash
     npx prisma db push && npx tsx prisma/seed.ts && next build
     ```
   - اضغط **Deploy**.
